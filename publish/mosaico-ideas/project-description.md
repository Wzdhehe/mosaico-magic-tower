# 魔塔 · 五十层试炼

把经典魔塔的资源取舍，装进口袋里的 Mosaico。

你不必赶时间。先看看战斗会损失多少生命，再决定先开哪扇门、把钥匙留给哪一层，或者先回去完成一个奇怪的委托。

## 五十层，不同的探索节奏

从断门城塞、沉水回廊、灰烬工坊，一路走进静默王城和星冠高塔。50 张原创地图包含守卫把守的成长资源、跨层钥匙路线、回访与可选奖励。最后一层是一屏完整呈现的对称王座大厅。

## 留意脚边较暗的墙砖

塔里有 8 间隐藏房。第一次走进暗墙，房间才会显现，NPC 会教你辨认。还有 3 条跨层小支线、可以反复拨动的水闸，以及三枚通向可选藏室的星记。某间房里还藏着一位终端机器人。

## 为小屏幕整理的操作

- 点击相邻格或滑动移动，战斗前显示预计损耗。
- 大地图随角色走到边缘自动切换视角，没有额外的视角按钮。
- 换层自动保存；传送点为 1 / 10 / 20 / 30 / 40 / 50 层，随章节解锁。
- “重开”可回到检查点或开始新游戏，新游戏需要再次确认。
- 一个设置按钮集成中英文、音量、亮度和 GitHub 地址。
- 中文对白使用放大的 24px 字体，长句自动换行并保留完整分页。
- 8 首原创循环配乐，覆盖标题、五个区域、决战和结局。

## 使用说明

适用于 ESP-Mosaico 主板，无需额外子板。通过 Vibe Mode 安装 Iris 固件包，欢迎开始新旅程。

当前为 **1.8.0-rc.2 测试版**。已完成五条整塔路线回放、实际 C 模拟器验证和早期版本的实机启动检查；完整实机试玩和平衡仍在继续。新版地图不兼容旧版游戏存档，升级后请开始新游戏。

封面为 AI 辅助主题插画；图库另附实机屏幕抓图和原生模拟器截图，插画不代表实际游戏视角。
