# 真正有收益的分叉：6F/9F 实作

依据《新人造塔避雷指南 V1.4.0》（用户提供的 28 页 PDF）在第 3–11、
15–24 页关于“闲置怪”“数值阈值”“信息可预判”“布局不能堆/空”的论述。
本文的地图设计和数值选择是本项目的实践，不是楼主的原话。

- **6F**：左边法师守防御宝石 +3；右边石魔守攻击宝石 +5。任意一个
  守卫均可开通前进路线；另一颗宝石不能从背后绕取。
- **9F**：左边石魔守防御 +3；右边怨灵守攻击 +5。北部另外设置
  一攻一防宝石，保留层内补给预算。玩家能只打一个守卫通关，
  也能承担更多战斗代价去拿第二颗宝石。
- **3/4/5F 与 7/8F**：原蓝钥匙/红钥匙跨层因果链未改。
- **商店涨价**：攻防共用次数，第 N 次购买需 15+10*(N-1) 金币，
  仍然每次属性 +3。菜单显示实时价格。不新增其他机制。
- **存档**：沿用 PR #1 的 v4 格式，仅更新已消费金币的内部合法性
  核算；暂不设计存档迁移。
- **范围**：仍为 11×11，贴图、画面大小、渲染频率、音频均不改。

四条完整塔路线的离线确定性模拟全部可赢（默认不购物）：

| 6F 守卫 | 9F 守卫 | 通关 HP | 攻击 | 防御 | 金币 |
|---|---|---:|---:|---:|---:|
| 石魔 | 怨灵 | 147 | 77 | 31 | 413 |
| 石魔 | 石魔 | 178 | 72 | 34 | 405 |
| 法师 | 怨灵 | 200 | 72 | 34 | 405 |
| 法师 | 石魔 | 189 | 67 | 37 | 397 |

这些是四条示例回放，不等于全局最优或“绝对无软锁”的证明。
金币包含战胜魔王所得的 150 金币，不能在 Boss 战前消费。
实际合并须以 GitHub Actions 的 C 模型逐动作回放、Python 分支
模拟和 Mosaico 实机游玩感受为准。
