# 第一章逐格设计：断门城塞

坐标从左上角(0,0)起；每行11格。数据源为`assets_src/level_design/region1_blueprint.py`。
这是模型已验证、等待真实UI接入的第一版；不是五十层整体成品。

图例：#墙，.地面，D下楼/落点，U上楼，y/b/r三色钥匙，Y/B/R三色门，
s史莱姆，v蝙蝠，k骑士，a攻击+5，d防御+3，p药+30，P药+80，S商店，n人物，%秘密墙，G章节石印。

核心链：4F首把蓝钥匙 → 3F双防/红钥匙或5F双攻 → 7F第二把蓝钥匙 → 补拿另一库 → 9F红门 → 10F队长。

路线与接入约束见[接入单](REGION1_INTEGRATION.md)。
