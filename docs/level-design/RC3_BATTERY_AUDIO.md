# RC3 电量与结局音乐

用户最终确认仅用颜色区分两种状态：断电白色，充电绿色；不画闪电，满电仍为绿色100%。图标左边距18px，避开圆角；15px内槽完整按电量填充，数字从x=42起，100%最右端为x=84，标题从x=92起。无有效读值显示`--`，模拟器不会伪造硬件电量。

电量模块在同一UI任务上借用BSP I2C总线，只读BQ27220的状态、电流、SOC寄存器；不调用可能改写电池配置的初始化，不改充电参数。每5秒最多查询一次，单次读超时10ms，失败下次周期重试。只有显示数值或状态变化才标记刷新；不改回合、存档和按键节奏。主机测试注入0/67/100%等数据，设备充电/拔线效果仍需实测。

音乐新增8号《Dawn above the Tower》：D大调、96BPM的通关号角；9号《One More Lantern》：D小调、56BPM的低声部挽歌。死亡/通关页的设置和重开子菜单保留对应曲目；通关后继续探索回到7号Home。所有曲目继续使用现有四声部整数合成器，6272字节实例，不新增音频渲染分配。

验收：故障注入I2C只读寄存器白名单、5秒节流、缺失/故障恢复；300次重复遥测不获取或提交帧；真实C渲染检查白/绿像素、无闪电及0/25/50/67/100%填充比例、标题/地图/设置页位置；全部10曲的音高节奏、峰值、DC、接缝和任意分块一致性；生产整塔路线验证通关/探索切曲，死亡/确认菜单单独回归。
